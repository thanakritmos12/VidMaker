# 🎬 VidMaker — Web Video Studio & AI Transition Director

ระบบเว็บแอปพลิเคชันสร้างคลิปวิดีโอ (Full HD 1080p MP4) จากรูปภาพและไฟล์เสียง MP3 พร้อมระบบเลือก **Transition 12 รูปแบบแยกแต่ละรูป** และ **โหมด AI แนะนำ Transition อัตโนมัติ (AI Transition Director)**

## ✨ ฟีเจอร์หลัก
- **ใช้งานง่าย (User-Friendly UI):** เลือกรูปภาพที่ต้องการใช้จากเครื่องคอมพิวเตอร์ (รองรับเลือกหลายรูปและ Drag & Drop)
- **Transition 12 รูปแบบ (ตั้งค่าแยกแต่ละรูปได้):**
  - `Crossfade`, `Ken Burns`, `Slide Left`, `Slide Right`, `Slide Up`, `Linear Wipe`, `Circle Iris`, `Dynamic Zoom In`, `Dynamic Zoom Out`, `Dip to Black`, `Camera Flash`, `Hard Cut`
- **โหมด AI แนะนำ Transition อัตโนมัติ:** วิเคราะห์โทนสี ความสว่าง และสัดส่วนภาพควบคู่กับจังหวะเพลง เพื่อเลือก Transition ที่เหมาะสมให้แต่ละรูปโดยอัตโนมัติ
- **พรีวิวเรียลไทม์ 60fps & ส่งออกไฟล์ MP4 (Full HD 1920x1080):** ดูตัวอย่างการเปลี่ยนภาพพร้อมเสียงเพลงและซับไตเติ้ลบนหน้าเว็บได้ทันที และเรนเดอร์เป็นไฟล์ `.mp4` พร้อมดาวน์โหลด

## 🚀 วิธีติดตั้งและรันใช้งาน

```bash
pip install -r requirements.txt
python app.py
```

จากนั้นเปิดเบราว์เซอร์ไปที่ **`https://vid-maker-eight.vercel.app/`**
